# 竹编 DIY 平台（团队共享项目）

本仓库供五人团队共同开发一个网页项目。目前先发布已讨论的产品范围和用户流程，**尚无可运行 Demo**。

## 已确认的 Demo 范围

- 扇面：三种输入通道生成适配扇面的表面图样，确认后走通选编法、编辑与实时预览、工艺检查、材料清单、竹条编号和图文教程。
- 自定义形状：三种输入通道生成几何载体形状，确认后走通同样的后续流程。生成的是形状，不是表面图样。
- 箱盒、包：仅显示载体选项，不接入生成或后续流程。

三种输入通道为参考图、自然语言描述和用户绘制。详细步骤见 [产品范围](docs/PRODUCT_SCOPE.md) 与 [用户流程](docs/USER_FLOW.md)。

## 当前状态与下一步

目前仅有文档草案，功能尚未实现。五人需审核两份文档，并共同确认扇面标准案例、工艺规则、自定义形状的数据表示和检查边界，以及模块间公共数据格式。确认后再补 `docs/CRAFT_RULES.md`、`docs/DESIGN_DATA.md`、`docs/ACCEPTANCE_CASES.md` 和标准 JSON 样例。

本仓库由产品与集成负责人 A 维护可运行主版本并负责合并与演示发布；建议 B 负责工艺验收，五人共同验收端到端流程。该分工建议仍待团队确认。网页启动方法将在代码落地后补充。
