# 后续组员执行清单

## A：产品与集成

- [ ] 组织锁定首个基准组合和“可制作”含义。
- [ ] 确认公共设计版本、D `sourceKey`、E `assessmentKey` 的存储位置。
- [ ] 页面只在 E 正式放行后开放材料单和教程。
- [ ] 任一设计变更后立即标记旧结果、清单和教程过期。
- [ ] 支持保存、打印或导出带版本信息的图文说明书。

## B：工艺与资料

- [ ] 对首个圆扇＋课程十字编组合完成真实试编。
- [ ] 锁定材料批次、宽厚、预处理和允许误差。
- [ ] 逐根记录备料长度、余量、损耗和失败。
- [ ] 审定裁切、收边、柄口连接和成品复核步骤。
- [ ] 提供照片、测量、适用范围和复核结论。
- [ ] 组织新手只依据说明书独立制作并记录卡点。

## C：创意输入与转译

- [ ] 为基准案例提供真实候选图样和已确认结果。
- [ ] 保持图样元素 ID 与来源稳定。
- [ ] 提供重点图案的用户声明，不靠颜色或面积猜测。
- [ ] 修改后生成新 `designRevision`。

## D：结构与制作数据

- [ ] 为每根竹篾提供毛坯、裁切后几何和稳定 ID。
- [ ] 计算制作级长度、余量、裁切线、收边和连接位置。
- [ ] 输出逐步操作 ID、相关竹篾/交点和操作前后状态。
- [ ] 自定义形状补齐外轮廓、有效区、毛坯、柄口和连接上下文。
- [ ] 相同输入重复计算结果一致，缺失数据不猜测。

## E：检查与放行

- [ ] 分别核验结构、工艺条件和物理证据覆盖。
- [ ] 每个问题给出位置、事实、原因、规则、证据和建议。
- [ ] 删除无条件 `pending` 的固定开关，改为证据覆盖判断。
- [ ] 只有全部必要项通过时允许正式材料单和教程。
- [ ] 保留 failed、pending 和过期案例的自动化测试。

## 共同出口条件

- [ ] 通过、失败、缺证据三个样例判断正确。
- [ ] 通过样例能生成逐根备料单和完整图文教程。
- [ ] 新手能独立完成，B 复核成品达到预定标准。
- [ ] 修改设计后旧产物立即失效并能重新生成。
- [ ] 新增编法或载体必须复制同一证据链，不能只增加预览。
