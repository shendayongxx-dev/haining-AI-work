# 竹编 DIY 平台 B 组交接包 v2.0：从工艺检查到可实操图文教程

交接日期：2026-11-03  
交接对象：A、C、D、E 及后续材料计算、教程生成、测试成员  
终极目标：用户完成自定义图样、载体和编法编辑后，系统只在证据覆盖且工艺检查通过时，导出与当前设计版本一致的备料清单和可实际操作的图文步骤。

## 1. 本包解决什么

本包把 B 组此前分散的三类资料整理为一条开发依赖链：

1. **工艺基线**：三种核心编法、六种正式载体、外侧基础编织连续性和工艺检查规则。
2. **教程证据**：十字编、人字编、四角孔编的原始步骤说明和步骤图片。
3. **生产化缺口**：实物试编记录、逐根备料长度、裁切余量、收边、柄口连接、成品偏差和新手验收。
4. **跨组接口**：B 需要提供什么，D 需要计算什么，E 如何放行，A 如何展示和使旧结果失效。

## 2. 当前状态必须如实表述

- 已锁定：三种编法的结构循环、六种载体的正式边界和有效图样区、固定载体外侧基础编织连续性、19 项工艺检查规则映射。
- 已有教程来源：三种编法均有步骤文本和图片；这些资料可以作为动作依据和页面原型素材。
- 尚未完成：覆盖当前组合和参数范围的 B 组实物试编证据、正式备料余量、通用收边和柄口连接验收。
- 因此首个基准案例仍为 `pending`。正式材料清单、正式制作教程、制作批准和导出必须继续关闭，直到满足本包的放行条件。

## 3. 首个建议基准案例

`FAN-ROUND-170-V1 + CROSS-COURSE-2X2-V1 + 固定材料规格 + 固定参数范围`

选择原因：圆扇几何最稳定；课程十字编已有清晰的四行循环和较完整步骤图片；适合首先验证从结构快照、工艺检查、材料计算到图文教程的全链路。

注意：不得把旧平编 `CROSS-1X1-V1` 的材料数值直接套入课程十字编，也不得将 21 经、21 纬、单根 290 mm 等接口演示口径直接表述为正式制作定额。

## 4. 放行依赖顺序

`B 实物试编证据 + D 制作级结构数据 → E 可制作判定 → 正式材料清单 → 图文教程 → 新手实做验收`

不能先把 E 状态改成通过，再补充证据；不能先开放教程按钮，再让用户承担验证成本。

## 5. 目录说明

- `01_B组当前基线与边界.md`：已确认内容和禁止误用事项。
- `02_首个基准案例与验收标准.md`：首个端到端案例的支持范围和通过标准。
- `03_B组实物试编记录模板.md`：B 必须补录的真实制作证据。
- `04_制作级数据与教程接口.md`：A/C/D/E 与 B 的最小对接字段。
- `05_材料计算与教程生成规则.md`：材料和图文步骤的生成原则。
- `06_后续组员执行清单.md`：按角色列出的后续任务和出口条件。
- `data/`：B 试编记录、材料和教程操作模板。
- `schemas/`：材料清单与教程步骤建议 Schema。
- `baselines/`：此前 B v1.2 与工艺检查 v1.5 的权威基线副本。
- `assets/`：三种核心编法的步骤说明和图片。
- `references/`：本轮路线图原文。

## 6. 权威源优先级

1. 当前设计与结构：D 的当前结构快照及其 `sourceKey`。
2. 工艺规则与证据：B 规则版本、适用范围和已复核试编记录。
3. 可制作判定：E 对当前结构、规则和证据的确定性核验结果。
4. 页面显示与导出：A 只展示与当前设计版本完全匹配的结果。

出现冲突时不得以教程文案、效果图或旧演示数字覆盖结构快照和实物证据。
