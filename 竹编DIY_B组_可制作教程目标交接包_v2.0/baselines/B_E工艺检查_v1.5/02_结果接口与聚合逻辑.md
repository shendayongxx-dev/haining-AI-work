# 结果接口与聚合逻辑 v1.5

## 1. 来源键分层

不得把 B 的版本号写回 D 快照。结果同时保存两个键：

```json
{
  "sourceKey": {
    "schemaVersion": "0.3",
    "designId": "DESIGN-001",
    "designRevision": 3,
    "generatedFromRevision": 3,
    "patternPlacementKey": "..."
  },
  "assessmentKey": {
    "resultSchemaVersion": "1.5",
    "craftRuleSetVersion": "B-CRAFT-CHECK-v1.5",
    "evidenceSetVersion": "B-EVIDENCE-v1.5",
    "craftCheckEngineVersion": "E-CHECK-v1.0",
    "carrierContextHash": "sha256:64位小写十六进制",
    "weaveId": "CROSS-COURSE-2X2-V1",
    "weaveSpecVersion": "WEAVE-SPEC-v1.2"
  }
}
```

`sourceKey` 由 D/A 定义并原样保留；`assessmentKey` 只描述本次工艺检查。公共适配器字段名最终由 A 冻结。

## 2. 自定义载体最小上下文

正式检查至少需要：

- `coordinateSpace`；
- `boundaryPointsMm`；
- `effectivePatternBoundaryPointsMm`；
- `rawBlankBoundaryPointsMm`；
- `handleContext.hasHandle` 明确布尔值；
- 若 `hasHandle=true`：`jointBoundaryPointsMm`、`motifExclusionBoundaryPointsMm`、`reinforcementBoundaryPointsMm`；
- `carrierContextHash`：覆盖上述字段及其版本的规范化哈希。

任何必要项缺失，`CUSTOM_CONTEXT_COMPLETE = pending`。不得从外轮廓推断有效区、毛坯或手柄情况。

`CUSTOM_HANDLE_CONTEXT` 是上述父规则的子检查/别名，不单独生成 `ruleResults`，也不重复增加 `pendingCount`。若问题只发生在手柄上下文，父规则记录使用 `location.region=handleContext`，并把 `basis.rulePath` 指向 `CUSTOM_CONTEXT_COMPLETE.children.CUSTOM_HANDLE_CONTEXT`。

## 3. 顶层结果

结果包含 `sourceKey`、`assessmentKey`、逐条 `ruleResults`、问题 `issues` 和关闭输出 `disabledOutputs`。`notApplicable` 必须存在于 `ruleResults`，不能静默跳过。

## 4. 聚合逻辑

1. 任一 `required` 或已触发 `conditional` 规则为 `failed`，总体为 `failed`。
2. 无 failed，但存在参与聚合的 pending，总体为 `pending`。
3. 所有适用必检规则均执行且通过，才可返回 `passed`。
4. `notApplicable` 不计入 passed/failed/pending 计数，但计入 `notApplicableCount`。
5. `summary` 必须由 `ruleResults` 计算，不允许调用方直接填写后不校验。
6. `issues` 只收录 failed/pending；其数量应等于 `failedCount + pendingCount`。

JSON Schema 可约束字段形状和非负计数；“summary 与 ruleResults 完全一致”仍需 E 运行时校验。

## 5. 重点图案规则

`HANDLE_MOTIF_EXCLUSION` 只有在输入提供用户/系统明确的 `priorityMotifBoundaryPointsMm` 时才可执行：

- 有标记且进入禁入区：failed；
- 明确声明无重点图案：notApplicable；
- 未提供标记能力或声明：pending。

不得把全部着色竹条自动解释为重点图案。

## 6. 版本失效

下列任一内容变化，旧结果转为 `stale`：D 来源键、设计修订、`patternPlacementKey`、载体上下文哈希、编法/规范版本、B 规则集或证据集版本、D 生成器版本、E 检查器版本。

## 7. 关闭输出

Schema 将以下字段固定为 `enabled:false`：`materialBom`、`tutorial`、`formalExport`、`productionApproval`。`weavingOrder.mode` 固定为 `structure-preview-only`。
