# 材料计算与教程生成规则

## 一、材料计算

正式材料清单必须由当前 D 结构快照与 B 实测规则共同计算。

### 1. 单根竹篾

`stockLengthMm = finishedVisibleLengthMm + setupAllowanceMm + trimWasteLengthMm + ruleRequiredReserveMm`

各项必须分别保留，不能只给总数；所有余量均须引用 B 试编记录。

### 2. 汇总项目

- 经篾和纬篾分别统计数量和长度；
- 记录逐根裁切表、总长度、余量和预计损耗；
- 另列收边材料、柄、连接材料、胶或线以及所需工具；
- 同时记录设计版本、结构来源、规则版本和证据 ID。

### 3. 禁止事项

- 不用成品轮廓内的可见弦长替代毛坯备料长度；
- 不用固定百分比替代尚未验证的余量；
- 不跨材料、编法和载体复用旧定额；
- `pending` 或 `failed` 不输出带“正式”标签的数量。

## 二、教程生成

教程是确定性结构数据与 B 审定工艺动作的组合，不由生图模型发明制作步骤。

### 1. 每一步必须回答

1. 拿哪根竹篾或哪组材料？
2. 放到哪里、从哪侧进入？
3. 在哪些竹篾上方或下方通过？
4. 操作完成后应呈现什么状态？
5. 用户如何自查，常见错误是什么？

### 2. 图像来源

- 排列、穿织和交点：优先从 D 结构快照生成 SVG/矢量高亮图。
- 裁切、收边和柄口连接：使用 B 审定并标注的实拍图。
- 效果图只用于展示，不得替代结构图和实拍动作证据。

### 3. 推荐章节

1. 成品与适用范围；
2. 材料和工具；
3. 竹篾编号图与裁切表；
4. 排经与起编；
5. 逐根穿纬与循环提示；
6. 松紧和形状校正；
7. 按正式边界裁切；
8. 收边；
9. 柄口加固与装柄；
10. 成品复核和错误处理。

### 4. 版本要求

教程头部显示设计、载体、编法、材料、结构、规则和证据版本；任一版本变化后，旧教程显示“已过期”，不能继续导出为正式说明书。
