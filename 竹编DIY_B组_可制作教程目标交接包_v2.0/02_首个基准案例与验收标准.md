# 首个基准案例与“可制作”验收标准

## 1. 建议组合

- 载体：圆形扇面 `FAN-ROUND-170-V1`
- 编法：课程十字编 `CROSS-COURSE-2X2-V1`
- 坐标：`A4_MM_210X297`
- 材料：由 B 在第一次正式试编前锁定同一批次、宽度、厚度、含水状态和允许误差
- 参数：第一轮固定，不开放自由缩放；扩大范围必须重新验证

## 2. “可制作”必须同时满足

1. **来源一致**：设计版本、载体版本、编法版本、材料版本和结构快照来源键一致。
2. **结构完整**：每根竹篾有稳定 ID；交点上下关系完整；裁切段可追溯至原竹篾。
3. **边界完整**：中心图样、外侧基础编织、收边施工带和柄口上下文齐全。
4. **参数合规**：竹篾宽厚、间距、最短可操作段、曲率或折角满足 B 的实测范围。
5. **证据覆盖**：当前组合和参数落在已复核试编记录的适用范围内。
6. **制作闭环**：备料、排经、逐根穿纬、校正、裁切、收边、装柄和成品复核均有审定动作。
7. **版本未过期**：用户修改图样、载体、编法、材料或参数后，旧检查、材料单和教程立即失效。

## 3. 三态输出

- `passed`：全部必要条件通过且有物理证据覆盖，可以生成当前版本的正式材料清单与教程。
- `failed`：存在明确不满足的结构或工艺条件，必须给出位置、原因、测得值、规则和修改建议。
- `pending`：缺少判断所需的上下文或物理证据，不给肯定结论，也不生成正式清单和教程。

## 4. 必备测试样例

| 样例 | 预期 | 目的 |
|---|---|---|
| 基准通过样例 | `passed` | 验证完整证据链与正式导出 |
| 明确失败样例 | `failed` | 验证问题定位、规则依据与修改建议 |
| 缺证据样例 | `pending` | 验证系统不会把未知情况误判为可制作 |
| 修改后样例 | 旧结果失效 | 验证版本与重新检查机制 |

## 5. 新手实做验收

由未参与开发的体验者只使用导出的说明书制作：

- 能识别需要拿取的竹篾编号；
- 能按图示确认从哪侧穿入、压在谁上或下；
- 能完成裁切、收边和装柄；
- 关键步骤不依赖开发人员口头补充；
- B 按预先锁定的尺寸、平整度、边缘、柄口和结构连续性标准复核。

测试人数、允许求助次数、合格阈值应在试验前锁定，不得在结果不佳后降低标准。
