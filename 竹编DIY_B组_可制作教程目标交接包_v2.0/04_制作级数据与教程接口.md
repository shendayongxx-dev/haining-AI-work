# 制作级数据与图文教程接口

以下为跨组核对清单。公共字段是否正式入库由 A 组织评审；B 不单方面修改公共接口。

## 1. C / A → D / E

- `designId`、`designRevision`；
- 已确认图样及稳定的元素 ID；
- 载体、编法、材料和参数版本；
- 重点图案声明：明确标记或明确“无重点图案”；
- 用户修改后产生新版本并使旧产物失效。

## 2. D → E / 材料 / 教程

### 每根竹篾

- `stripId`、方向、序号和材料规格；
- 毛坯几何、成品可见段和毫米坐标；
- 成品可见长度、起编/夹持余量、裁切损耗、正式备料长度；
- 裁切线、边缘和柄口连接上下文；
- 与交点、分段和操作步骤的映射。

### 每个交点

- `crossingId`、经纬竹篾 ID；
- 上下层关系；
- 毫米位置；
- 所属编法循环及操作顺序。

### 每个制作动作

- `operationId`、顺序和阶段；
- 关联 `stripIds`、`crossingIds`、`segmentIds`；
- 操作前后结构状态；
- 高亮范围、箭头方向和图示视口。

## 3. B → E / 材料 / 教程

- 规则 ID、版本和适用范围；
- 阈值、单位、测量方式和失败后果；
- 试编证据 ID、材料批次和复核状态；
- 备料余量、损耗、收边和连接的实测依据；
- 审定动作文本、完成标准、常见错误及实拍图片。

## 4. E → A / 材料 / 教程

- 总体 `passed / failed / pending`；
- 每项规则结果与 `notApplicable`；
- 具体位置、事实/测得值、原因和修改建议；
- `sourceKey`、`assessmentKey`、规则和证据引用；
- `allowFormalBom`、`allowFormalTutorial`、`allowFormalExport`。

只有当前版本 `passed` 且三个许可均为真，A 才能开放正式材料清单和教程。

## 5. 一致性要求

- 同一竹篾在预览、检查、材料单和教程中使用同一 `stripId`。
- 教程文字和图示引用同一 `operationId`。
- 设计、结构、规则、证据任一版本变化，旧 E 结果、材料单和教程全部过期。
- 缺失字段显式为空并触发 `pending`，不得用默认值掩盖。
