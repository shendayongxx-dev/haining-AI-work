# A → D：自定义形状竹编结构正式接入请求

日期：2026-10-30  
当前基线：`main` 提交 `7d491bc`（自定义形状竹编视觉示意已上线）  
负责：D 负责结构计算与预览；A 负责页面状态和集成；C 提供已确认的形状数据；B 提供工艺边界；E 后续接检查与教程。

## 1. 用户报告的问题

复现路径：选「自定义形状」→ 直接绘制一个闭合轮廓 → 生成并确认候选 → 选当前平编演示 → 进入「编辑预览」。

原先编辑页只显示一块米色实心轮廓，并提示「当前结果尚未进入 D 扇面结构计算」。用户的预期是：**进入编辑页时，该轮廓已经由竹篾交织构成；调节参数时，竹篾结构随之更新**。结果确认页可以展示未编织的几何候选，但编辑页不能退回到实心形状。

## 2. A 已做的临时接入

- `src/modules/d/CustomStructurePreview.tsx`：读取 C 的 `carrier_shape`，用 SVG 裁切显示横纵竹条和挑一压一的局部上下关系；根数、宽度、颜色、缩放会更新画面。
- `src/App.tsx`：自定义形状进入编辑页时改用此预览；圆扇仍使用 `calculateFanStructure` + `StructurePreview`。
- 页面继续标为「结构示意／工艺待验证」，E 检查仍为 `pending`。

**这只是视觉示意，不是 D 的正式结构交付。**目前线段按外接框排布后由 SVG 裁切；没有逐根竹条的真实裁切端点、几何长度、唯一编号、交点集合及可供 E 使用的同版本结构快照。请 D 审阅并替换或重构该临时组件，不要把屏幕 SVG 当作结构数据反推。

## 3. 请 D 实现的范围

首个案例只需使用 C 已确认的**单个闭合、无孔自定义轮廓**与当前 `CROSS-1X1-V1` 演示编法，保持工艺 `pending`。不要求在本次实现生图模型、三种 B 正式编法或任意复杂多孔轮廓；遇到暂不支持的几何应给出明确的阻断／待接入状态，不能悄悄退回实心图。

1. 从已确认的 `carrier_shape` 读取 `shapeId`、`coordinateSpace`、`components[].outerBoundary.pointsMm`、`holes`，拒绝未确认、未闭合或无效轮廓；坐标继续使用 `210 × 297 mm`、左上原点。
2. 用纯计算函数在轮廓内生成经纬竹条，计算每根竹条与边界的交段、毫米端点、几何长度和稳定编号；交点记录所关联的两根竹条、位置及 `top`。若有孔洞，需正确排除；如首版不支持，明确拒绝并记录限制。
3. 让 SVG 预览**只读取同一次计算得到的结构快照**。调整根数、竹条宽度、颜色或图形大小后，A 增加 `designRevision`，D 用当前确认结果重算；异步结果应按版本核对。显示缩放不能偷偷改变保存的毫米坐标。
4. 快照至少能关联 `designId`、`designRevision/generatedFromRevision`、`confirmedGenerationId`、`shapeId`、编法 ID、参数、竹条列表、交点列表及 `pending` 原因。字段和单位请先与 A、C、E 对齐，不要单方面改变公共 `docs/DESIGN_DATA.md`。
5. 继续区分视觉交织与工艺认证：没有 B 对自定义形状的适用编法、边缘和收边依据时，不能给出「可制作」或正式材料清单。

## 4. 与其他组的接口对齐

- **C → D**：C 的 `carrier_shape` 是载体几何，不是扇面 `surface_pattern`。请核对闭合、孔洞、稳定 ID、毫米坐标及错误状态；如需要形状简化或最小特征约束，列出具体规则交由 C/B 确认。
- **B → D**：B 确认自定义边界的适用编法、最小窄颈／残段、边缘收边和装柄等工艺条件。缺依据时保留 `pending`；不要从当前圆扇规则推断自定义形状可制作。
- **D → A/E**：D 给 A 一个由已确认形状和参数生成快照的入口、预览组件及错误状态；E 只消费快照，不读取 SVG。A 保持页面选择和版本失效逻辑。

## 5. 验收与交付

- 同一闭合轮廓从候选确认进入编辑页后，立即呈现**轮廓内的竹条交织结构**，而非实心填充；轮廓外没有竹条。
- 调节根数和宽度后，预览、竹条数、交点数与同版本快照一致；重置后回到默认值。颜色和缩放变化也按已对齐的设计版本规则处理。
- 未闭合／自交／过窄／多孔等案例按支持范围给出明确状态，不产生伪结构或「可制作」结论。
- 圆扇绿色三角形路径仍可运行，现有圆扇快照和编辑预览不回退；`pnpm build` 通过。
- D 交付时注明：修改文件、输入／输出示例、结构快照版本、运行与复现方法、已知限制，以及需要 A/C/B/E 确认的问题。
