# A → C：图文绘制接入条件

页面已将文字与参考图合并为一个图文入口。输入包含同一 `inputVersionId` 下的参考图、用户描述和目标类型。描述是对该参考图的提取与改造要求，不能当作独立文字生成通道。

| 当前载体 | 目标输出 | 结果确认页展示 |
| --- | --- | --- |
| 固定扇面 | 新生成的纹样参考图，以及与当前 `carrierRef` 对齐的 `surface_pattern` | 新参考图与可编织的表面图样 |
| 自定义形状 | 新生成的形状参考图，以及 `carrier_shape` | 新参考图与可编织载体轮廓 |

模型接口需返回生成图资源引用、结构化结果、生成版本、来源图资源引用、原始描述、`inputVersionId`、`generationId` 和 `generationRevision`。参考图与新生成图必须是不同资源；生成图先显示在结果确认页，确认后才进入编法和结构预览。固定扇面的 `carrierRef` 仍以版本化载体注册表为准，自定义形状的 `carrierRef` 为 `null`。

目前仓库没有可调用的图文生成模型、生成图资源存储和从图到结构化结果的适配器。A 页面仅收集并预览原始输入，提交时明确提示未接入；C 现有固定三角形或叶片演示结果不得冒充图文模型输出。手势控制仅在自定义形状显示为待接入入口，尚未提交输入。
