# A：D v0.3.6 网页准入规则

本次合并采用 D v0.3.6 的结构计算、毛坯完整铺网、图样放置快照与来源验证，但按产品决定限制网页入口。D 的引擎支持组合范围不等于当前网页开放范围。

| 扇面 | 可选编法 | 参数调节 |
| --- | --- | --- |
| 圆形／月圆式 | 平编候选、课程版十字编、人字编、四角孔编 | 可调经纬条数、竹条宽度、图样大小、底色；间距自动计算 |
| 长圆式 | 课程版十字编、人字编、四角孔编 | 不开放；使用 D 默认结构参数与默认底色 |
| 八角式 | 课程版十字编、人字编、四角孔编 | 不开放；使用 D 默认结构参数与默认底色 |

已确认创意在这三种固定扇面之间可直接试换，不返回输入页；从圆扇平编切到非圆形扇面时自动改选课程版十字编。每次扇面、编法或圆扇参数变化都递增设计版本。自定义形状仍走现有的独立结构演示，不使用固定扇面 D v0.3.6 快照。

圆扇的图样大小由 D 的 `patternPlacement.scale` 表示，C 的原始 `sourcePattern` 不变。C 的非单位 `SurfacePattern.transform` 公共语义仍待冻结。E v0.3.6 消费尚未接入网页，所有工艺与实物状态继续待验证。

验证：三个原有共同案例、网页开放的十个组合、圆扇参数案例、D 来源篡改拒收、TypeScript 与 Vite 构建。
