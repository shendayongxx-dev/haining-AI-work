# A：D v0.3.6 网页准入规则

本次合并采用 D v0.3.6 的结构计算、毛坯完整铺网、图样放置快照与来源验证。三种固定扇面均开放四种编法；自定义形状继续使用独立结构演示，并按相同编法矩阵提供四种预览。

| 扇面 | 可选编法 | 参数调节 |
| --- | --- | --- |
| 圆形／月圆式 | 平编候选、课程版十字编、人字编、四角孔编 | 可调经纬条数、竹条宽度、图样大小、底色与图样色；间距自动计算 |
| 长圆式 | 平编、课程版十字编、人字编、四角孔编 | 可调经纬条数、竹条宽度、图样大小、底色与图样色；间距自动计算 |
| 八角式 | 平编、课程版十字编、人字编、四角孔编 | 可调经纬条数、竹条宽度、图样大小、底色与图样色；间距自动计算 |

已确认创意在这三种固定扇面之间可直接试换，不返回输入页，当前编法保持选择。每次扇面、编法、参数或配色变化都递增设计版本。自定义形状仍走独立结构演示，不使用固定扇面 D v0.3.6 快照。

三种扇面的图样大小均由 D 的 `patternPlacement.scale` 表示；配色修改生成新设计版本的调色板，已确认 C 候选保持原样。C 的非单位 `SurfacePattern.transform` 公共语义仍待冻结。E v0.3.6 消费尚未接入网页，所有工艺与实物状态继续待验证。

验证：三个原有共同案例、网页开放的十二个固定扇面组合、四种自定义形状矩阵、参数和配色案例、D 来源篡改拒收、TypeScript 与 Vite 构建。
