# A 组选色交接：推荐方案与用户取色

当前编辑页允许用户分别调整底色（经向竹条／圆扇底色）和图样色（纬向竹条／圆扇图样），也可从本机选择的实物照片点击取色。照片只在浏览器中读取，不进入设计 JSON 或服务器。每次有效改色都会增加 `designRevision` 并重算 D 的预览快照；重置回到页面示意配色。

现有绿色色块是联调示意，不是经实物照片确认的材料色卡。B 的现有工艺文件未给出照片、采样位置、光照条件、对应竹篾或染色材料和可用性结论。页面因此保持“工艺 pending”，照片取色也只代表屏幕视觉目标色，不等于材料可采购或可制作。

后续对接：

1. **B** 提供可用于项目的实物照片及来源/使用权限、材料名称、颜色处理方式、取色区域和实物验证状态；如有颜色范围或组合限制，给出依据。
2. **A** 根据 B 的资料建立带来源与状态的推荐色板，并保留用户 DIY 选色；不得将自定义色自动标为“可制作”。
3. **C/D** 核对图样色板和 D 竹条颜色段的来源关联。当前自定义形状只有 `warpColor`、`weftColor` 两个视觉目标色；若需逐区着色，应共同评审数据格式后再扩展。
4. **E** 根据 B 已验证的材料与颜色规则判断颜色可行性；缺少依据时继续返回待验证。

此轮没有修改 `docs/DESIGN_DATA.md` 的公共字段或单位。
