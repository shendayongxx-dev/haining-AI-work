# 正式扇面载体规范

载体ID：`FAN-ROUND-170-V1`  
载体名称：圆形／月圆式竹编团扇  
版本：1.0

## 1. 坐标空间

- 单位：mm。
- 画布宽：210mm。
- 画布高：297mm。
- 原点：A4纵向画布左上角。
- X轴：向右为正。
- Y轴：向下为正。

页面可响应式缩放，但保存、计算和导出必须使用上述毫米坐标。

## 2. 正式扇面外轮廓

- 几何类型：圆。
- 圆心：`(105,110)mm`。
- 半径：85mm。
- 直径：170mm。
- 外接框：`x=20mm，y=25mm，width=170mm，height=170mm`。
- 轮廓ID：`BOUNDARY-ROUND-170-V1`。

## 3. 有效图样区域

- 几何类型：与外轮廓同心的圆。
- 圆心：`(105,110)mm`。
- 半径：75mm。
- 直径：150mm。
- 外接框：`x=30mm，y=35mm，width=150mm，height=150mm`。
- 边界ID：`PATTERN-ROUND-150-V1`。
- 面积：约17671.5mm²；扣除扇柄连接保留区后的可用面积由几何模块计算。

## 4. 收边带

- 位于半径75–85mm之间的环形区域。
- 径向宽度：10mm。
- 面积：约5026.5mm²。
- 该区域不放置必须完整显示的图案元素。
- 使用20mm布条沿轮廓对折包边，正反面各覆盖约10mm。

## 5. 扇柄连接保留区

- ID：`HANDLE-RESERVE-20X25-V1`。
- 矩形范围：`x=95–115mm，y=170–195mm`。
- 宽：20mm。
- 高：25mm。
- 用途：扇柄插接、粘接和局部加固。
- 该区域可以存在背景纹理，但不得放置文字、主体图案或必须辨认的细节。

## 6. 毛坯编织区域

- 21根经向竹篾×9mm＝189mm。
- 21根纬向竹篾×9mm＝189mm。
- 毛坯外接框：`x=10.5mm，y=15.5mm，width=189mm，height=189mm`。
- 毛坯覆盖170mm扇面后，四周理论裁切操作余量为9.5mm。

## 7. 参数边界

| 参数 | 正式值 | 接受范围 |
| --- | --- | --- |
| 扇面直径 | 170mm | 169–171mm |
| 有效图样直径 | 150mm | 不得超过150mm |
| 收边径向宽度 | 10mm | 9–11mm |
| 扇柄连接区宽度 | 20mm | 不得小于20mm |
| 扇柄插接高度 | 25mm | 不得小于25mm |
| 竹篾宽度 | 9mm | 8.5–9.5mm |
| 竹篾厚度 | 0.5mm | 0.4–0.6mm |
| 单根备料长度 | 280–300mm | 不得短于280mm |
| 经向数量 | 21根 | 固定 |
| 纬向数量 | 21根 | 固定 |

## 8. 形制依据

圆形／月圆式是传统团扇的基础形制；本规范的170mm工程尺寸由42根、9mm宽竹篾形成的189mm毛坯反推确定，使外轮廓、裁切操作余量、10mm收边和150mm有效图样区域能够同时落在同一数据体系中。
