# 请团队评审：设计数据与 SVG 实时预览方案

> 发给 A、B、C、D、E 共同评审。本文件是讨论稿，不代表接口或工艺规则已定稿。详细字段草案见 [DESIGN_DATA.md](DESIGN_DATA.md)。请直接在仓库提出修改建议，或按文末格式回复 A。

## 已确认的产品范围

- 扇面与自定义形状均支持参考图、自然语言描述、用户绘制三种输入，并走通生成确认、选编法、编辑与实时预览、工艺检查、材料清单、竹条编号和图文教程。
- 扇面生成适配载体的**表面图样**；自定义形状生成**几何载体形状**。箱盒、包仅展示选项。
- 实时调节与预览使用 **SVG**，不使用 Grasshopper。

## 提议的模块交接

1. **C 输入生成**：A 传入已选载体；C 把三类输入转成与编法无关的结构化结果。扇面输出 `surface_pattern`，自定义形状输出 `carrier_shape`；保留输入引用和独立的生成版本。最终竹条网格不由 C 生成。
2. **A 确认与流程**：让用户预览、重新生成或确认结果；未确认不能进入正式编辑和检查。
3. **D 编辑与 SVG**：读取已确认结果、所选编法和参数，计算网格、竹条数据与交织关系并绘制 SVG。设计数据使用 mm，SVG 通过明确的映射变换显示。疏密、宽度、图样大小和配色变化时，同步更新设计版本与画面。
4. **E 检查与教程**：读取当前设计版本及 D 提供的唯一竹条编号、几何和交织数据，输出问题、材料、编号和步骤；设计变化后旧检查和教程失效。依据不足时仅展示标注为演示内容的页面，不生成或导出正式资料。
5. **B 工艺依据**：补充编法、竹条规格、参数边界、材料计算和真实制作顺序，并注明资料来源与试编状态。

## 暂定共同规则

- 设计数据是唯一当前数据源；SVG 是其视图，不用 SVG 图片反推材料清单。
- 几何和尺寸统一使用 `mm`；SVG 通过 `mmToSvg`、原点和轴方向映射显示，页面缩放、平移不改变设计数据。
- 修改形状、图样、编法或工艺参数后递增设计版本，并使旧检查和教程失效。
- 缺少 B 的工艺依据时，可展示标注为“演示内容”的 SVG 或页面，检查状态为“待验证”，不生成或导出正式材料清单与制作教程。

## 已收到的 C、D、E 反馈与待协调项

- 已采纳：C 输出编法无关结果；D 选编法后计算网格、竹条和 SVG；扇面图样与自定义几何互斥；生成版本、设计版本、下游来源版本分开；D 分配竹条唯一 ID，E 沿用；SVG 坐标映射独立于 mm 工艺坐标。
- 待 C、D 确认：`surface_pattern` 的最小结构、图样网格与竹条密度不一致时的重采样责任及规则。
- 待 B、D、E 确认：开口、自交、孔洞、多部件形状能否继续编辑及其工艺检查边界。
- D 提议的 130 mm 半径、65 经×65 纬、3 mm 竹条样例仅供接口联调，必须标注“演示数据，待 B 验证”，不得作为正式工艺标准。
