# 竹编 DIY 平台：用户流程与页面状态（草案）

> 供五人团队审核；描述目标交互，不表示页面已经实现。扇面与自定义形状均为本轮完整流程；箱盒、包仅展示选项。用户绘制和自定义形状纳入前序开发。

| 步骤 | 用户操作 | 页面状态与输出 | 进入下一步的条件 |
| --- | --- | --- | --- |
| 1. 选载体 | 选择扇面、箱盒、包或自定义形状 | 扇面与自定义形状进入完整流程；箱盒和包仅显示选项及“暂未开放”提示 | 已选可交互载体 |
| 2. 选输入通道 | 扇面选择鼠标绘制或图文绘制；自定义形状另显示待接入的手势控制 | 图文绘制同时收集参考图和描述，描述是对参考图的提取与改造要求；保留原始输入以便修改 | 输入有效且真实生成完成 |
| 3. 确认生成结果 | 查看、接受或返回修改 | 固定载体展示适配表面图样；自定义载体展示生成的载体形状，不能当作表面图样 | 用户明确确认结果 |
| 4. 选编法 | 选择已支持的基础编法 | 在载体与所选编法下显示初始竹条效果；可返回更换结果 | 编法适用于当前载体，且已选定 |
| 5. 编辑与实时预览 | 调整疏密、竹条宽度、图样大小、配色 | 每次有效调整都更新预览和同一份设计数据；无效输入给出提示 | 用户提交当前设计进入检查 |
| 6. 工艺检查 | 查看检查结果并按建议修改 | 不通过时显示问题位置、原因、修改建议并返回编辑；资料不足时显示待验证状态 | 检查通过，且必要工艺依据已确认 |
| 7. 获取制作资料 | 查看材料清单、竹条编号、图文教程 | 资料基于通过检查的当前设计，步骤按经确认的真实制作顺序排列 | 完成；编辑后需重新检查并更新资料 |

## 扇面演示主路径

选择扇面 → 鼠标绘制表面图样，或上传参考图并用文字指定提取与改造内容 → 预览并确认扇面表面图样 → 选择基础编法 → 编辑参数并观察竹条实时变化 → 工艺检查 → 查看材料、竹条编号及图文教程。图文绘制目标是生成新的纹样参考图及可供结构消费的表面图样；当前真实图文模型未接入，页面保留输入并明确提示，不能将固定演示三角形当成生成结果。用户在确认前可返回修改输入；检查不通过时返回编辑；修改已通过的设计会使旧检查结果和旧教程失效。

编辑页的三种已接入固定扇面可直接试换：已确认的创意图样保持原始来源，页面以所选扇面重新生成结构预览，不要求返回创意输入或再次确认。编法也可在编辑页直接切换。每次切换扇面或编法都递增设计版本，使旧工艺检查和制作资料失效。圆形、长圆式、八角式和自定义形状均可选平编、课程版十字编、人字编、四角孔编。三种固定扇面均可调经纬条数、竹条宽度、图样大小、底色和图样色。扇面与自定义形状属于不同结果类型，跨这两类切换仍需重新生成对应创意结果。

编辑页可上传实物照片，在浏览器本地提取主要颜色，也可点击照片补取颜色。提取结果先进入可选色板，再由用户将任一颜色应用到底色或指定图样色。图样色按 `paletteId` 分别保存；当前单色候选显示一个色位，后续多色候选显示多个独立色位。每次应用颜色都更新设计版本并重算预览；照片本身不上传。

## 自定义形状演示路径

选择自定义形状 → 鼠标绘制外轮廓，或上传参考图并用文字指定提取与改造内容 → 预览并确认生成的几何载体形状 → 选择适用编法 → 编辑参数并实时预览 → 工艺检查 → 获取材料清单、竹条编号和图文教程。这里生成的是形状，不是表面图样。手势控制显示为待接入入口。图文模型与手势输入未接入前，不生成伪候选；若形状超出已验证的工艺边界，检查应指出问题或标记待验证，不得输出可制作结论。

## 状态与异常约定

- 生成失败或输入无法稳定转译：说明原因，允许修改输入并重试；复杂输入的简化方式待团队确认。
- 生成结果与载体不匹配：不可确认进入编辑，需重新生成或调整输入。
- 编法不适用或参数越界：提示原因，保留可编辑数据，不输出“可制作”结论。
- 工艺依据不足：标记“待验证”，不得推断材料用量或编造制作步骤；是否阻止导出由团队结合 B 的规则确定。
- 当前设计发生变化：检查状态退回待检查；材料、编号和教程需重算。

## 待团队明确的页面行为

箱盒、包在本轮只展示选项，不进入生成流程。扇面与自定义形状均支持三种输入通道并进入完整流程；自定义形状生成结果的数据格式、尺寸、适用编法和工艺边界仍须团队确认并记录。
