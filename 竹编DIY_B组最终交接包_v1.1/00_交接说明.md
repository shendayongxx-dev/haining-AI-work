# 竹编 DIY 平台 B 组最终交接包 v1.1

修复日期：2026-10-31  
核心范围：十字编、人字编、四角孔编；6 种正式首版扇面载体。

## v1.1 外侧区域修复

本版本补充 D 组反馈的“有效图样区外侧仍需完整竹编”规则：

1. 先在 `rawBlank` 毛坯范围生成完整基础竹编，圆扇首版毛坯为 189 × 189 mm。
2. 再以正式扇面 `boundary` 裁切，得到 `trimmedProduct`。
3. `effectivePatternBoundary` 只限制用户图案、颜色变化或重点纹样，不限制竹篾是否存在。
4. 正式外轮廓与有效图样区之间的区域称为 `outerBaseWeaveZone`，必须延续所选基础编法。
5. 外侧区域中的竹篾编号、节距、宽度和压挑相位必须与中心区域连续，不得重新起算、旋转、拉伸或使用装饰条纹替代。
6. 最外缘另保留收边带；收边带位于竹编之上，不能用来掩盖缺失的外侧竹编。

对应说明、示意截图和 D 组差异记录位于 `04_D组差异修复/`。

- `02_正式载体规范/正式载体规范.md`：6 种载体的形状、尺寸、有效区、参数边界和收边规则。

## 3. 首轮联调建议

首轮只开放 3 个编法和 6 个扇面。编法、扇面分别按 `weaveId`、`carrierId` 选择，载体切换时保持同一毫米坐标接口。推荐测试顺序：

1. 圆形 + 十字编：验证最简单的密排正交网格。
2. 长圆式 + 人字编：验证错位循环与裁切。
3. 八角式 + 四角孔编：验证开放网格、方孔尺寸和多边形边界。
4. 再覆盖芭蕉式、五角海棠型、宫腰方形的非圆边界裁切。

## 4. 验收边界

- 图形预览不得只显示颜色贴图，必须显示竹篾网格及上下交织关系。
- 所有竹篾应有唯一编号，并能从预览、材料单、问题定位和教程步骤相互追溯。
- 正式导出必须使用毫米坐标，不能把屏幕像素当作真实尺寸。
- 材料用量是首轮计算口径，正式制作前仍需用真实竹篾做一次实物校准。
- 步骤图片必须随步骤一起分发，不得只复制纯文本说明。
