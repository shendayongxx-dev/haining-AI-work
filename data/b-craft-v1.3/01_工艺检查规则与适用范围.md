# 工艺检查规则与适用范围

## 一、适用对象

### 固定扇面

适用于 B v1.2 已登记的 6 种正式载体：圆形、长圆式、八角式、芭蕉式、五角海棠型、宫腰方形。几何权威源为 `carriers.json`，不得用预览 PNG 或手工描摹边界代替。

### 自定义形状

适用于用户提交的闭合二维轮廓。自定义形状必须同时提供正式外轮廓、有效图样区、毛坯边界、坐标空间和是否含手柄/连接结构。缺少任一必要上下文时返回 `pending`。

### 编法

本阶段只检查：

- `CROSS-COURSE-2X2-V1`
- `HERRING-3X3-V1`
- `SQUARE-HOLE-1X1-V1`

其他编法不在 B v1.3 的已交付范围内，返回 `failed / UNSUPPORTED_WEAVE`，不能按中文名称猜测规则。

## 二、固定载体规则

| 规则 ID | 检查内容 | 判定 | 依据 |
|---|---|---|---|
| `FIXED_CARRIER_ID_MATCH` | `carrierId`、边界和规范版本与 B v1.2 一致 | 不一致为 failed | `CARRIER-SPEC-v1.2` |
| `BOUNDARY_GEOMETRY_MATCH` | 正式边界、有效区、手柄区与权威 JSON 一致 | 超出几何容差为 failed | `carriers.json` |
| `RAW_BLANK_COVERS_BOUNDARY` | 毛坯覆盖完整正式外轮廓 | 未覆盖为 failed | 先编毛坯再裁切 |
| `EFFECTIVE_BOUNDARY_INSIDE` | 有效图样区完全位于正式外轮廓内 | 越界为 failed | B v1.2 载体规范 |
| `OUTER_BASE_WEAVE_CONTINUITY` | 有效区外至正式外轮廓内保持同一竹篾 ID、节距和交织相位 | 中断或重置为 failed | 外侧基础竹编同步规则 |
| `HANDLE_MOTIF_EXCLUSION` | 手柄连接区不放置需完整辨识的重点图案 | 违反为 failed | 各载体 handleExclusion |
| `EDGE_FINISH_EVIDENCE` | 收边类型、加固方式和实物记录齐全 | 当前缺记录为 pending | B v1.2 规范，待实物验证 |

## 三、自定义形状规则

| 规则 ID | 检查内容 | 判定 | 说明 |
|---|---|---|---|
| `CUSTOM_CONTEXT_COMPLETE` | 坐标空间、外轮廓、有效区、毛坯、连接结构声明齐全 | 缺失为 pending | 缺上下文不能推断 |
| `CUSTOM_BOUNDARY_CLOSED` | 外轮廓和有效区均闭合 | 不闭合为 failed | 确定性几何规则 |
| `CUSTOM_BOUNDARY_SIMPLE` | 外轮廓无自相交、重复边和零长度边 | 违反为 failed | 确定性几何规则 |
| `CUSTOM_EFFECTIVE_INSIDE` | 有效区完全位于正式外轮廓内 | 越界为 failed | 与固定载体同一语义 |
| `CUSTOM_RAW_BLANK_COVERS` | 毛坯覆盖自定义外轮廓及裁切余量 | 未覆盖为 failed | 先编毛坯再裁切 |
| `CUSTOM_OUTER_BASE_CONTINUITY` | 外轮廓与有效区之间保持连续基础编织 | 中断或重置为 failed | 外侧基础竹编规则 |
| `CUSTOM_HANDLE_CONTEXT` | 若形状含柄，必须提供柄口/禁入/加固区域 | 缺失为 pending | 不允许自动猜测位置 |
| `CUSTOM_EDGE_FINISH_EVIDENCE` | 自定义曲线、尖角、凹角的收边方案有验证记录 | 无记录为 pending | 当前没有通用实物阈值 |

## 四、编法与结构规则

| 规则 ID | 适用编法 | 检查内容 | 判定 |
|---|---|---|---|
| `WEAVE_MATRIX_MATCH` | 三种 | `topStripId` 与编法矩阵一致 | 不一致为 failed |
| `STRIP_ID_TRACEABLE` | 三种 | `stripId → segmentId → crossingId` 双向可追溯 | 断裂为 failed |
| `COLOR_SEGMENT_COVERAGE` | 三种 | 颜色段连续、不重叠并完整覆盖可见段 | 缺口/重叠为 failed |
| `CROSS_4X4_PHASE` | 十字编 | 使用锁定的 4×4 四行错位矩阵 | 不一致为 failed |
| `HERRING_6X6_PHASE` | 人字编 | 压三挑三，相邻行逐格错位 | 不一致为 failed |
| `SQUARE_HOLE_1X1_PHASE` | 四角孔 | 挑一压一并保持规则间距 | 交织错误为 failed |
| `SQUARE_HOLE_PARAMETER_EVIDENCE` | 四角孔 | 9/6/15 mm 参数是否有实物记录 | 当前为 pending |

## 五、工程复核规则

以下规则可以定位问题，但当前没有足够实物依据形成自动失败阈值：

- `SHORT_VISIBLE_SEGMENT`
- `OPEN_HALF_HOLE_AT_EDGE`
- `CORNER_REINFORCEMENT_REQUIRED`
- `LOBE_VALLEY_REINFORCEMENT_REQUIRED`
- `HANDLE_REINFORCEMENT_REQUIRED`

统一输出：

```text
status = pending
severity = review
```

E 必须返回具体 `stripId / segmentId / crossingId / positionMm / boundaryRef`，不能只返回笼统文字。

## 六、问题定位与修改建议

每个问题至少包含：

- `issueId`
- `ruleId`
- `status`
- `location`
- `reason`
- `suggestion`
- `basis`
- `evidenceStatus`

修改建议只能引用现有规则，例如“扩大毛坯”“把有效区移回外轮廓内”“恢复同一编法相位”“补充柄口区域”“提交收边试编记录”。不得在缺少依据时生成新的毫米阈值。
