# B → E 工艺检查交接包 v1.3

交接日期：2026-11-02  
依赖基线：`CARRIER-SPEC-v1.2`、`WEAVE-SPEC-v1.2`、D→E 结构快照 v0.3  
本包范围：固定扇面与自定义形状的工艺检查。

## 1. 本阶段开放能力

- 接收固定扇面或自定义形状的结构快照。
- 返回 `passed / failed / pending`。
- 每个问题必须返回位置、原因、修改建议、规则依据和证据状态。
- 固定扇面使用 B v1.2 的正式边界、有效图样区、手柄区和外侧基础编织规则。
- 自定义形状执行几何合法性、结构连续性和依据完整性检查。
- 结果必须绑定设计、载体、编法、生成器、检查器和证据版本；任一输入变化时旧结果失效。

## 2. 本阶段关闭能力

- `materialBomEnabled = false`
- `tutorialEnabled = false`
- `formalExportEnabled = false`
- `productionApprovalEnabled = false`
- 现有 `weavingOrder` 仅用于结构预览和交织关系核对，不得解释为正式制作流程。

## 3. 三态语义

### passed

当前适用且具有有效依据的必检规则全部通过，没有 `failed`，也没有会影响结论的 `pending`。`passed` 仅表示通过本版本的结构与工艺筛查，不表示已经通过实物制作验证。

### failed

结构违反已有明确依据且可确定判定的规则，例如边界不闭合、自相交、有效区越界、编法矩阵不一致、外侧基础编织中断、可见段颜色覆盖不完整或身份追溯断裂。

### pending

缺少必要字段、规则依据、验证记录或实物阈值；或问题需要人工/实物复核。当前短竹篾、开放半孔、异形转角、瓣谷、收边方法、材料余量和正式制作可行性均不得自动判为 `passed` 或 `failed`。

## 4. 当前结论边界

三组结构集成案例仍缺少 B 组实物测量、收边照片和材料记录，当前最终状态保持 `pending`。E 可以验证接口、定位问题和输出修改建议，但不得把它们作为正式制作通过样例。
