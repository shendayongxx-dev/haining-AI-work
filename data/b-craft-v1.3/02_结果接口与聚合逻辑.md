# 结果接口与聚合逻辑

## 1. 顶层结果

```json
{
  "checkId": "CHK-...",
  "status": "passed | failed | pending",
  "assessmentScope": "structural-and-craft-screening",
  "productionReady": false,
  "physicalValidation": "not-completed",
  "sourceKey": {},
  "summary": {},
  "issues": [],
  "disabledOutputs": {}
}
```

`passed` 不能自动把 `productionReady` 改为 `true`。正式制作批准属于后续阶段。

## 2. 三态聚合

按以下顺序聚合：

1. 任一适用的确定性规则为 `failed`，总体为 `failed`。
2. 没有 `failed`，但存在影响结论的 `pending`，总体为 `pending`。
3. 所有适用必检规则均有有效依据且通过，才返回 `passed`。
4. `notApplicable` 规则不参与聚合，但需保留在检查记录中。

## 3. 问题位置

```json
{
  "carrierSpace": "A4_MM_210X297",
  "pointMm": {"x": 105, "y": 185},
  "region": "outerBaseWeaveZone",
  "boundaryRef": "effectivePatternBoundary",
  "stripId": "V005",
  "segmentId": "V005-S01",
  "crossingId": "X-V005-H012"
}
```

无对应字段时使用 `null`，不得伪造定位。

## 4. 规则依据

```json
{
  "documentId": "CARRIER-SPEC-v1.2",
  "rulePath": "common.outerBaseWeaveRule",
  "evidenceLevel": "documented | structure-tested | physical-validated",
  "evidenceRecordIds": []
}
```

只有 `physical-validated` 才能支持实物阈值。`documented` 可以支持确定性结构规则，但不能支持材料余量、收边强度等生产结论。

## 5. sourceKey 与版本失效

A、D、E 共同使用以下失效键：

```json
{
  "schemaVersion": "1.3",
  "designVersion": "...",
  "designRevision": 1,
  "carrierType": "fixed | custom",
  "carrierId": "...",
  "customBoundaryHash": null,
  "carrierSpecVersion": "CARRIER-SPEC-v1.2",
  "weaveId": "...",
  "weaveSpecVersion": "WEAVE-SPEC-v1.2",
  "craftRuleVersion": "...",
  "structureGeneratorVersion": "...",
  "craftCheckEngineVersion": "E-CHECK-v1.0",
  "evidenceSetVersion": "B-EVIDENCE-v1.3"
}
```

以下任一项改变，旧检查结果标记为 `stale` 并禁止继续显示为有效结果：

- 设计版本或修订号；
- 固定载体 ID、载体规范版本；
- 自定义边界、有效区、毛坯或柄口上下文，反映在 `customBoundaryHash`；
- 编法 ID、编法规范或工艺规则版本；
- 裁切、段排序、颜色切分、交点归属算法版本；
- E 检查器版本；
- B 证据集版本。

## 6. 与 A 对齐的状态展示

- `passed`：显示“本版本工艺检查通过”，同时显示“未获得正式制作批准”。
- `failed`：显示问题数量、首要问题位置和修正入口。
- `pending`：显示缺失依据/记录清单，不得用绿色通过样式。
- `stale`：设计或规则已经变化，需要重新检查。

## 7. 关闭输出

```json
{
  "materialBom": {"enabled": false, "reason": "physical allowance formula not validated"},
  "tutorial": {"enabled": false, "reason": "craft-to-instruction conversion deferred"},
  "formalExport": {"enabled": false, "reason": "production approval unavailable"},
  "weavingOrder": {"mode": "structure-preview-only"}
}
```
